[[obsidian/obsidian-lifeos-build-3|3편]]에서 속성을 안 채우면 노트가 유령이 된다고 했다. 그런데 사람은 매번 프론트매터를 채우지 않는다.

그러니 **채우게 만드는 게 아니라 안 채워도 되게 만들어야 한다.** 이 글은 그 얘기다.

## 목표 상태

새 노트를 만들 때 내가 하는 결정은 하나뿐이다. **무슨 타입인가.** 그리고 그 결정은 명령을 고르는 순간 이미 끝나 있다.

`⌘N`을 누르면 템플릿 목록이 뜬다. "노트"를 고르면 이런 파일이 만들어진다.

```yaml
---
type: note
created: 2026-08-09
persona: personal
status: inbox
category: memo
tags: []
---

## 템플릿을 "명령"으로 만든다

Templater 플러그인에는 잘 안 쓰이는 기능이 하나 있다. **Template Hotkeys.** 설정에서 템플릿 파일을 여기에 등록하면 그 템플릿이 명령 팔레트의 명령이 된다. "템플릿 삽입"이 아니라 **"이 타입의 노트 만들기"**가 되는 것이다.

지금 등록해둔 건 열 개다.

노트 · 프로젝트 · 미디어 · 스크랩 · 지식 · 엔티티 · 글쓰기 · 회의록 · 이슈 · 타임스탬프

여기에 각각 단축키를 걸 수도 있다. 설정 문서에는 `⌘⌥1`, `⌘⌥2` 식으로 걸라고 적어놨었다. 그런데 **실제로는 안 쓰게 됐다.** 지금 쓰는 건 `⌘N` 하나다. Templater의 "새 노트 만들기(템플릿 선택)" 명령에 걸어두고, 뜨는 목록에서 두세 글자 쳐서 고른다.

이유는 단순하다. 타입이 열 개면 단축키도 열 개인데, **열 개짜리 단축키는 외워지지 않는다.** 하나를 외우고 목록에서 고르는 편이 실제로 더 빨랐다. 문서에 적어둔 계획과 실제 사용이 갈린 사례라 그대로 적어둔다.

## 파일명에 영타 별칭을 박았다

템플릿 파일명이 이렇게 생겼다.

```
Templates/노트 shxm.md
Templates/회의록 ghldmlfhr.md
Templates/프로젝트 vmfhwprxm.md
Templates/이슈 dltb.md
```

뒤에 붙은 문자열은 오타가 아니다. **한글을 영자판으로 친 것**이다. `shxm`은 "노트", `ghldmlfhr`은 "회의록"이다.

왜 이렇게 했냐면, 한글 입력 상태에서 명령 팔레트를 열면 그대로 영타가 쳐지기 때문이다. "회의록"을 찾으려고 치면 `ghldmlfhr`이 입력되고, 검색은 아무것도 못 찾는다. 그러면 한/영을 전환하고 다시 쳐야 한다.

파일명에 영타를 박아두면 **어느 자판 상태에서 쳐도 같은 템플릿이 나온다.** 1초짜리 마찰이지만 하루에 열 번 반복되면 안 쓰게 되는 종류의 1초다.

| 템플릿 | 영타 |
|---|---|
| 노트 | shxm |
| 프로젝트 | vmfhwprxm |
| 미디어 | aleldj |
| 스크랩 | tmzmfoq |
| 지식 | wltlr |
| 엔티티 | dpsxlxl |
| 글쓰기 | rmftmrl |
| 회의록 | ghldmlfhr |
| 이슈 | dltb |
| 발행 | qkfgod |

## 템플릿이 질문을 하기도 한다

전부 프론트매터만 채우는 건 아니다. 몇 개는 만들면서 한두 가지를 물어보고, 그 답으로 파일명과 필드를 자동으로 정한다.

**회의록**은 시리즈를 고르게 한다.

```js
const series = await tp.system.suggester(
  ["TA 주간회의", "변경관리", "(단발성 회의)"],
  ["TA 주간회의", "변경관리", ""],
  false, "회의 시리즈?"
);
```

정기 회의를 고르면 파일명이 `TA 주간회의 2026-08-09`으로 자동 지정되고 `series` 필드까지 채워진다. 단발성을 고르면 제목을 묻고 `2026-08-09 <제목>`이 된다. 회의록은 이름 규칙이 흐트러지기 제일 쉬운 타입이라 손에 맡기지 않았다.

**이슈**는 제목을 묻고 `이슈 2026-08-09 <제목>`으로 파일명을 만든다. 그리고 본문 `## 조치` 섹션에 **발생 시각을 미리 찍어둔다.**

```
## 조치
- 14:32 발생
- 
```

장애 대응 중에 시각을 손으로 적을 여유는 없다. 나중에 복기할 때 제일 아쉬운 게 시간이라 생성 시점에 한 줄 박아둔다.

**엔티티**는 종류를 고르게 하고, 그 답에 따라 **본문 구조를 바꾼다.**

```js
const body = kind === "area"
  ? "## 범위\n…\n\n## 유지 기준\n…\n\n## 관련\n-"
  : "## 관련\n-";
```

`area`(끝나지 않는 책임 영역)를 고르면 `## 범위`와 `## 유지 기준`이 딸려 온다. 3편에서 "유지 기준 없는 area는 존재 이유가 없다"고 썼는데, 그 규칙을 문서로만 두지 않고 **템플릿이 강제하게** 만든 것이다. 사람이 지켜야 하는 규칙보다 안 지킬 수 없는 구조가 낫다.

**발행 템플릿**만 유일하게 파일을 옮긴다. 공개 글은 `Publish/` 폴더 안에 있어야 하고 그 폴더 구조가 그대로 사이트 URL이 되기 때문에, 만들 때 어느 폴더인지를 묻는다. 이때 **실재하는 폴더만 후보로 보여준다** — 없는 폴더를 제안 목록에 넣어두면 지운 폴더가 유령처럼 계속 나타난다. 그리고 같은 이름이 이미 있으면 뒤에 번호를 붙인다. **기존 발행본을 덮어쓰는 사고를 막기 위해서다.**

## 저널은 폴더가 트리거다

날짜 노트만은 다르게 동작한다. Templater의 **폴더 템플릿** 기능으로 `Journal/Daily`, `Journal/Weekly`, `Journal/Monthly`, `Journal/Quarterly`, `Journal/Yearly` 다섯 폴더에 각각 템플릿을 걸어뒀다. 저 폴더에 파일이 생기면 자동으로 해당 템플릿이 적용된다.

파일명 형식은 이렇다.

| 주기 | 형식 |
|---|---|
| 일간 | `YYYY/MM/YYYY-MM-DD (ddd)` |
| 주간 | `gggg/gggg-[W]ww` |
| 월간 | `YYYY/YYYY-MM` |
| 분기 | `YYYY/YYYY-[Q]Q` |
| 연간 | `YYYY` |

일간 노트는 `⌘9`로 연다. 오늘 노트가 없으면 만들어지고 있으면 그냥 열린다.

여기 함정이 하나 있는데, 일간 파일명의 `(ddd)` — 요일 표기다. 이게 **로케일에 따라 `(Sat)`이 되기도 `(토)`가 되기도 한다.** 그리고 옵시디언 캘린더 플러그인은 파일명을 엄격 모드로 파싱하기 때문에, 기대하는 로케일과 다르면 기존 노트를 못 찾고 새로 만들겠냐고 묻는다. 이 얘기는 7편에서 자세히 한다.

지금은 시작 스크립트 한 줄로 못박아뒀다.

```js
window.moment.locale("en");
```

Templater의 **Startup Templates**에 등록해두면 옵시디언을 켤 때 실행된다. UI 언어는 한국어 그대로 두고 날짜 표기만 영어로 고정하는 것이다.

## 타임스탬프

`⌘I`를 누르면 커서 자리에 이게 찍힌다.

```
2026-08-09 (Sat) 21:14
```

템플릿 파일은 딱 한 줄이다.

```js
<%* tR += moment().locale("en").format("YYYY-MM-DD (ddd) HH:mm") %>
```

일간 노트의 "오늘의 기록"에 잡생각을 적을 때 이걸로 시각을 찍으며 쓴다. 나중에 하루를 되짚을 때 순서와 간격이 보인다.

여담인데, 원래 이건 `⌘;`에 걸어뒀었다. 그런데 템플릿 파일명에 영타 별칭을 붙이면서 파일 경로가 바뀌었고, **단축키 설정은 옛 경로를 그대로 가리키고 있어서 죽은 매핑이 됐다.** 지금 `⌘;`는 아무 일도 하지 않는다. 파일명을 바꿀 때 단축키가 따라오지 않는다는 건 알아둘 만하다.

## 실제로 쓰는 단축키 전부

내가 지금 손에 붙어 있는 것들이다. 옵시디언 기본값이 아니라 직접 바꾼 것만 적는다.

| 키 | 하는 일 |
|---|---|
| `⌘N` | 템플릿 골라서 새 노트 |
| `⌘⇧N` | 새 할일(TaskNotes) |
| `⌘O` | Omnisearch 전문 검색 |
| `⌘I` | 커서 위치에 타임스탬프 |
| `⌘9` | 오늘 일간 노트 |
| `⌘0` | 작업 공간(레이아웃) 전환 |
| `⌘⇧D` | 파일 삭제 |
| `⌘↑` `⌘↓` | 현재 줄 위아래로 이동 |
| `⌘⇧H` `⌘⇧L` | 뒤로 / 앞으로 |
| `⌘[` `⌘]` | 왼쪽 / 오른쪽 사이드바 토글 |
| `⌃D` | 라이트/다크 전환 |
| `⌘⇧R` | 무작위 노트 |
| `⌘R` | 앱 새로고침 |
| `⌘\` | 터미널 포커스 |

몇 개는 설명이 필요하다.

`⌘⇧H` / `⌘⇧L`을 뒤로·앞으로에 건 건 vim의 `h`/`l`이 좌우 이동이라서다. 링크를 타고 들어갔다가 돌아오는 동작이 하루에 수십 번 있는데 기본 단축키는 손이 멀다.

`⌘⇧D` 삭제와 함께 **삭제 확인창을 껐다.** 위험해 보이지만 옵시디언은 삭제한 파일을 휴지통으로 보내고 파일 복구 기능도 켜져 있다. 확인창은 되돌릴 수 없을 때 의미가 있지, 되돌릴 수 있는 동작에 붙으면 그냥 클릭 한 번이 늘 뿐이다.

`⌘⇧R` 무작위 노트는 회고용이다. 볼트를 굴리다 보면 쓰고 잊은 노트가 쌓이는데, 가끔 아무거나 열어보는 게 인박스를 훑는 것보다 나을 때가 있다.

## 자동으로 안 하는 것

**`active`는 자동으로 안 찍는다.** 모든 노트는 `inbox`로 태어난다. 미디어만 예외로 `someday`(위시리스트)로 시작한다.

이건 게을러서가 아니라 3편에서 정한 `status`의 정의 때문이다. `status`는 진행도가 아니라 **"내가 이걸 봤는가"**다. 템플릿이 `active`를 찍으면 그 순간 "봤다"고 거짓말을 하는 셈이고, 그러면 뒤에 나올 큐레이션 루프가 통째로 죽는다. `active`는 사람이 한 건씩 열어보고 판단했을 때만 붙는다.

**태그도 자동으로 안 붙인다.** 캡처할 때는 태그를 손대지 않는다. 3편에서 정한 대로 태그는 "나중에 같이 찾을 묶음"이 보일 때 붙이는 것이고, 그건 만드는 시점에 알 수 없다.

**제목과 본문은 당연히 사람 몫이다.** 자동화의 목표는 생각을 대신하는 게 아니라 **생각과 무관한 결정을 없애는 것**이다. 어느 폴더에 넣을지, 오늘이 며칠인지, 지금이 업무 시간인지는 생각할 가치가 없는 결정이다. 그건 기계가 한다.

## 아이패드에서도 같은 속도로

주 사용환경이 아이패드인데 거기엔 단축키가 없다. 그래서 Advanced URI 플러그인으로 각 명령을 URL로 만들었다.

```
obsidian://advanced-uri?vault=CASE&commandid=templater-obsidian:create-Templates/노트 shxm.md
```

이걸 iOS 단축어 앱의 "URL 열기"에 넣고 홈 화면 위젯으로 깐다. 타입별 버튼이 홈에 있으면 아이패드에서도 두 번 탭으로 노트가 만들어진다.

여기 함정이 두 개 있다.

**`commandid`에 `create-` 접두사가 빠지면 앱만 열리고 아무 일도 안 난다.** `templater-obsidian:Templates/노트 shxm.md`가 아니라 `templater-obsidian:create-Templates/노트 shxm.md`여야 한다. 조용히 실패해서 원인 찾기 어렵다.

**URI를 손으로 쓰지 말 것.** 경로에 한글과 공백이 있어서 인코딩이 필요하다. Advanced URI의 "Copy URI for command" 명령을 쓰면 정확한 형태가 클립보드에 복사된다.

모바일 툴바에는 명령을 네 개만 남겼다. 되돌리기, 다시하기, 툴바 설정, **그리고 검색.** 폴더가 없는 볼트에서 모바일이 할 일은 결국 쓰기와 찾기 둘뿐이다.

## 화면 자체도 손을 봤다

노트 만드는 마찰과 별개로, 화면에서 쓸데없는 걸 걷어냈다.

**인라인 제목을 껐다.** 옵시디언은 본문 맨 위에 파일명을 큰 글씨로 띄워주는데, 파일명이 곧 제목인 볼트에서는 같은 문장이 탭·헤더·본문 세 군데에 나온다. 껐더니 화면이 조용해졌다.

**속성은 항상 펼쳐둔다.** 이 볼트에서 프론트매터는 부속이 아니라 본체다. 접어두면 안 채우게 된다.

**앱을 켜면 대시보드가 열린다.** 마지막에 보던 파일이 아니라 항상 `Dashboard.md`다. 어제 뭘 보다 껐는지는 오늘 아침에 중요하지 않다. 오늘 뭐가 있는지가 중요하다.

**링크 자동 갱신을 켰다.** 파일명을 바꾸면 그 파일을 가리키는 모든 링크가 따라온다. 제목을 자유롭게 바꿀 수 있어야 파일명이 제목 역할을 할 수 있다.

**첨부는 전부 `Files/` 한 곳에 모은다.** 노트 옆에 흩어지면 폴더 없는 구조가 이미지 때문에 깨진다.
